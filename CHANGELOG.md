# Changelog

## 5.0.0

- Reborn as **Codex Change Safe**, a cross-SCM delivery orchestrator rather than a PR narrative generator.
- Add GitHub PR and GitLab MR create/update lifecycle operations.
- Add deterministic Delivery Preflight and Change Manifest with zero default model calls.
- Consume Codex Review Safe / Commit Safe public range evidence.
- Add Change Receipt v1 and managed PR/MR sections.
- Add CODEOWNERS reviewer routing, labels, draft/ready flow, required checks, approvals, conflicts and discussion gates.
- Add GitHub auto-merge / merge queue and GitLab auto-merge capability profiles.
- Add GitHub.com/GHES and GitLab.com/Self-Managed provider abstraction.
- Hard-cut old `safeCodexPr.*` compatibility surface.
